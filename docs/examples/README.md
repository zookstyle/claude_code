# n8n 워크플로우 예제

이 폴더에는 다양한 n8n 워크플로우 예제가 포함되어 있습니다.

## 📋 예제 목록

추후 다음과 같은 예제들이 추가될 예정입니다:

- **ai-agent-workflow.json**: AI 에이전트를 활용한 워크플로우
- **webhook-workflow.json**: 웹훅 트리거 워크플로우
- **error-handling-workflow.json**: 에러 처리가 포함된 워크플로우
- **api-integration-workflow.json**: 외부 API 통합 예제

## 🎯 사용 방법

1. 예제 JSON 파일 다운로드
2. n8n에서 **Import from File** 선택
3. 다운로드한 JSON 파일 선택
4. 필요한 credentials 설정
5. 워크플로우 활성화

## ⚠️ 주의사항

- 예제 파일에는 API 키나 비밀번호가 포함되어 있지 않습니다
- 실제 사용 전에 본인의 credentials를 설정해야 합니다
